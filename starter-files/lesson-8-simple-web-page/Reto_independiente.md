# Tu turno: personaliza la página

Abre https://onecompiler.com/html y usa el ejemplo de la lección 8 como punto de partida.

1. Cambia «Mi espacio creativo» por un título propio.
2. Escribe tres pasatiempos diferentes en la lista.
3. Cambia el color del título principal en CSS. Puedes probar `green` o `purple`.
4. Cambia las palabras «Aprender HTML» por otro texto, conservando el destino del enlace.

Puedes utilizar datos inventados.

Ejecuta el código y comprueba:

- ¿Se ve el nuevo título?
- ¿Aparecen tus tres pasatiempos como elementos separados?
- ¿Cambió el color del título?
- ¿El enlace muestra el nuevo texto y sigue funcionando?

Desafío opcional: añade un cuarto pasatiempo y explica con tus palabras la diferencia entre `margin` y `padding`.
