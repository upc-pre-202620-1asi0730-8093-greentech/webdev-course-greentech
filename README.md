# Fundamentos de Desarrollo Web

## Resumen del Curso

En este curso de aproximadamente 1 hora se introducirá a estudiantes de secundaria a la creación de páginas web con HTML y CSS. 

Para llevar a cabo el curso no se necesitará descargar algún programa, ¡solo un navegador web como Google Chrome será suficiente!.

**Duración total**: ~60 minutos  
**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación  
**Prerrequisitos**: Ninguno  
**Herramientas necesarias**: ¡Solo un navegador web! Se sugiere Chrome, Firefox, Safari o Edge  
**Repositorio del curso**: [https://github.com/upc-pre-202620-1asi0730-8093-greentech/webdev-course-greentech](https://github.com/upc-pre-202620-1asi0730-8093-greentech/webdev-course-greentech)

## Secuencia de la lección

### Lección 1: ¿Qué es el desarrollo web? (6 minutos)

- **Descripción**: Averigua de qué están hechas las páginas web y como puedes crearlas con HTML y CSS.
- **Enlace**: [Ver la lección]()
- **Consejos clave**: Define la estructura del contenido con HTML y aplica estilos con CSS.
- **Empieza a programar**: [Open CodePen]()

### Lección 2: Introducción a HTML (7 minutos)

- **Descripción**: Conoce qué es HTML y como puedes escribirlo.
- **Enlace**: [Ver la lección]()
- **Consejos clave**: Crea elementos escribiendo entre `<` y `>`. Escribe el contenido de una pagina usando `<html>`, `<head>`, `<body>`.
- **Práctica**: [Clic para programar]() **¡Comienza al instante, sin descargas!**

### Lección 3: Elementos de HTML (6 minutos)

- **Descripción**: Aprende a usar etiquetas básicas de HTML.
- **Enlace**: [Ver la lección]()
- **Consejos clave**: Usa las etiquetas `<h1>` a `<h6>`, `<p>`, `<ul>` y `<table>`.
- **Práctica**: [Clic para programar]() 

### Lección 4:  Más Elementos de HTML (6 minutos)

- **Descripción**: Aprende a usar etiquetas de HTML con atributos.
- **Enlace**: [Ver la lección]()
- **Consejos clave**: Usa las etiquetas `<a>`, `<img>` y conoce sobre sus atributos.
- **Práctica**: [Clic para programar]() 

### Lección 5: Introducción a CSS (6 minutos)

- **Descripción**: Conoce qué es CSS y como puede decorar un HTML. 
- **Enlace**: [Ver la lección]()
- **Consejos clave**: Vincula CSS a la página web y prueba propiedades como `background-color`.
- **Práctica**: [Clic para programar]() 

### Lección 6: Propiedades de CSS (7 minutos)

- **Descripción**: Aplica colores, estilos y fuentes a una página web.
- **Enlace**: [Ver la lección]()
- **Consejos clave**: Distingue texto y fondo, elige letras legibles y utiliza `padding`, `margin` y `border` para dar espacio a una tarjeta.
- **Recursos**: [Guion y preparación](scripts/lesson-6-css-properties/lesson-6-css-properties.md) · [Presentación](scripts/lesson-6-css-properties/lesson-6-css-properties-presentation.pptx) · [Actividad inicial](starter-files/lesson-6-css-properties/) · [Solución](completed-examples/lesson-6-css-properties/)

### Lección 7: Selectores de CSS (5 minutos)

- **Descripción**: Aprende a decorar elementos específicos de una página web.
- **Enlace**: [Ver la lección]()
- **Consejos clave**: Aplica propiedades a elementos en general, grupos de elementos, clases e identificadores.
- **Práctica**: [Clic para programar]() 

### Lección 8: Desarrollo de una página web sencilla (12 minutos)

- **Descripción**: Combina HTML y CSS para crear una página con presentación, pasatiempos, imágenes, enlace y un campo de texto de práctica.
- **Video**: Pendiente de publicación.
- **Consejos clave**: Organiza el contenido, aplica estilos, adapta las imágenes y comprueba el resultado.
- **Recursos**: [Guion y preparación](scripts/lesson-8-simple-web-page/lesson-8-simple-web-page.md) · [Presentación](scripts/lesson-8-simple-web-page/lesson-8-simple-web-page-presentation.pptx) · [Actividad inicial](starter-files/lesson-8-simple-web-page/) · [Solución](completed-examples/lesson-8-simple-web-page/)
- **Proyecto final**: [Personaliza tu página](starter-files/lesson-8-simple-web-page/Reto_independiente.md). Cambia el título, tres pasatiempos, el color del título y el texto del enlace.

### Lección 9: Consejos y Próximos Pasos (5 minutos)

- **Descripción**: Conoce buenas prácticas, errores comunes y dónde puedes aprender más.
- **Enlace**: [Ver Lección]()
- **Consejos Clave**: Valida el código y explora documentaciones web.
- **Recursos**: [Guion y preparación](scripts/lesson-9-tips-and-next-steps/lesson-9-tips-and-next-steps.md) · [Presentación](scripts/lesson-9-tips-and-next-steps/lesson-9-tips-and-next-steps-presentation.pptx) · [Actividad inicial](starter-files/lesson-9-tips-and-next-steps/) · [Solución](completed-examples/lesson-9-tips-and-next-steps/)
